One word, first thought: **petrichor** — the smell of rain on dry earth. A single vivid word, no explanation, no second draft. This program writes exactly that one word (no trailing newline) to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty, where an AI judge compares words two at a time and crowns the most interesting one. Surprise, vividness and a spark of wit beat safe filler — petrichor carries all three.

## Run it

```sh
node main.ts
```
